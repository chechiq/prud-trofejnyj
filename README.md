# Пруд трофейный

Сайт-визитка центра рыболовства «Пруд трофейный» (Мошковский район, Новосибирская область).

Сайт лежит в `site/`: статичные HTML, CSS и JS без сборки. На главном экране пруд в сумерках, курсор — стеклянная капля, в ней видно рыб под водой. Дальше идут сцены «О пруде», «Фото», «Цены» и «Как добраться».

## Локально

```bash
python -m http.server 8790 --directory site
```

Открыть http://localhost:8790.

## Публикация

При пуше в `main` workflow `.github/workflows/pages.yml` выкладывает `site/` на GitHub Pages. В настройках репозитория: Pages → Source: GitHub Actions.
